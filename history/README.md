# history/ — история проб протоколов

Накопленные результаты пробника по разным устройствам, провайдерам и сетям: по ним `zoo probe --rank` и блок «Лучшие протоколы» в админке выбирают протоколы под ваши условия, а вы видите, как менялась картина со временем. Каталог можно коммитить в репозиторий: IP-адресов здесь нет.

```
history/
  recipients.txt       публичные ключи, которым шифруются сырые отчёты
  YYYY-MM.jsonl        анонимные строки: по одной на пару «прогон, протокол»
  raw/<id>.json.age    полный отчёт пробника, зашифрованный age (с IP — открывает только владелец ключа)
```

## Модель приватности

| Что | Где лежит | Кто видит |
|---|---|---|
| Анонимная строка: время (до часа, UTC), псевдоним сервера (`LABEL`, не адрес), провайдер и номер ASN, страна, тип сети, метка, устройство, протокол, вердикт, задержка, скорость | `*.jsonl`, открытым текстом | всем, у кого есть доступ к репозиторию |
| Сырой отчёт: адрес сервера, ваш прямой IP, IP выхода, журналы клиентов, заметки, пользователь | `raw/*.age`, зашифрован | только владельцы приватных ключей из `recipients.txt` |
| Приватный ключ | у владельца, в репозиторий не попадает никогда | — |

Что делает zoo, чтобы IP не попал в jsonl (`zoolib/probe/export.py`, проверяется юнит-тестами):

- в строку берутся только перечисленные поля; адрес сервера, прямой IP, IP выхода, город, заметки, пользователь, имя хоста не копируются вообще;
- каждое текстовое значение (провайдер, псевдоним, метка, устройство) проходит очистку: всё, что похоже на IPv4 или IPv6, заменяется на `x`; после очистки строка проверяется ещё раз, и если IP-подобное осталось, она отбрасывается;
- метки `--tag` и `--device` при вводе проверяются: до 40 символов, буквы, цифры и `. _ + - / @ ( )`, IP-подобное не принимается;
- время округляется до часа, чтобы не привязывать строку к минуте вашего действия; `id` — первые 16 hex-знаков sha256 всего отчёта, по нему IP не восстановить.

Что остаётся видно в открытом jsonl: провайдер, страна, тип сети, метка, устройство и час прогона. Если репозиторий публичный, не пишите в метки ничего личного (`--tag mobile-mts`, а не `--tag дома-у-Васи`) и учтите: «MTS, Pixel 7, 14:00 UTC» уже указывает на конкретного человека для тех, кто его знает. Не хотите этого — храните `history/` в приватном репозитории или не коммитьте `*.jsonl`. Коммит необратим: история git остаётся навсегда.

Сырые отчёты шифрует [age](https://github.com/FiloSottile/age) (формат с публичными ключами SSH: `ssh-ed25519` и `ssh-rsa`). Если приватный ключ утечёт, расшифруются все отчёты, зашифрованные на него, в том числе старые в истории git; смена `recipients.txt` защищает только новые. Ключ с парольной фразой age запрашивает при расшифровке.

## Как набирать историю

**1. Пробник на устройстве пишет прямо в `history/`** (Docker, без сервера в цепочке; подробности запуска — [docker/probe/README.md](../docker/probe/README.md)):

```bash
docker run --rm --cap-add NET_ADMIN --device /dev/net/tun \
    -v "$PWD/probe:/data" -v "$PWD/history:/history" zoo-probe --tag mobile-mts --device pixel7
```

Каталог `/history` внутри контейнера включает запись: анонимные строки дописываются в `history/YYYY-MM.jsonl`, сырой отчёт — в `history/raw/<id>.json.age`, если в `history/recipients.txt` есть ключи (age есть в образе). Повторный запуск не дублирует записи.

**2. Прогоны сервера и присланные отчёты копятся на сервере** (`/var/lib/vpn-zoo/probe-history.sqlite`, файл 0600): `zoo probe --local` записывает каждый прогон сам, клиентские отчёты — страница «Проверка» (форма с метками) или с вашей машины:

```bash
scripts/history.sh push root@СЕРВЕР --tag mobile-mts --device pixel7    # probe/probe-report.json → история сервера
scripts/history.sh pull root@СЕРВЕР                                     # сервер → history/ (без дублей)
git add history && git commit -m "history: прогоны за неделю"
```

`pull` отправляет на сервер `history/recipients.txt`, `zoo history export --tar` возвращает архив, и скрипт объединяет его с `history/`. Пользователь — `root` или с `sudo` без пароля; `-p ПОРТ` для нестандартного порта SSH. Без `age` на сервере (фаза 09 не смогла скачать) выгрузка содержит только jsonl.

## Расшифровка сырого отчёта

```bash
scripts/history.sh decrypt history/raw/<id>.json.age              # ключ ~/.ssh/id_ed25519
scripts/history.sh decrypt -i ~/.ssh/vpn_key history/raw/*.age
```

Скрипт берёт `age` из PATH. Нет его — выберите:

- Windows: `winget install FiloSottile.age`; или `scripts/history.sh install-age` (закреплённая версия, проверка sha256 по `scripts/versions.env`, кладёт в `~/.local/bin`);
- macOS: `brew install age`; Linux: `apt install age`;
- без установки: если собран образ `zoo-probe`, в нём есть `age`, и `decrypt` запускает его через Docker (ключ с парольной фразой так не откроется).

Вручную: `age -d -i ~/.ssh/id_ed25519 history/raw/<id>.json.age > отчёт.json`.

## Формат строки jsonl

Один JSON-объект на строку, ключ `ts` первый (сортировка строк = по времени). Нет значения — нет ключа.

| Ключ | Что |
|---|---|
| `ts` | час прогона, UTC: `2026-10-05T14Z` |
| `id` | идентификатор отчёта (одинаков у всех строк одного прогона; он же имя файла в `raw/`) |
| `mode` | `remote` — с клиентской машины, `local` — с сервера |
| `server` | псевдоним сервера (`LABEL`) |
| `isp`, `asn`, `country` | провайдер, номер ASN и страна прямого подключения клиента (см. ниже) |
| `net` | `wifi`, `ethernet` или `cellular`, если определился |
| `tag`, `device` | ваши метки |
| `proto`, `verdict` | протокол и вердикт (`OK`, `SLOW`, `FREEZE_16K`, …) |
| `latency_ms`, `p90_ms`, `jitter_ms`, `loss_pct` | задержка через туннель: медиана, p90, джиттер, потери малых запросов |
| `rtt_ms` | время TCP-connect к порту сервера |
| `down_mbps`, `up_mbps` | скорость загрузки и отдачи, Мбит/с |

Откуда провайдер и страна: пробник спрашивает `speed.cloudflare.com/meta` (JSON с `asn`, `asOrganization`, `country`) по прямому подключению, без туннеля; запрос идёт на тот же хост, с которого пробник качает тестовые файлы, адрес в запрос не входит. Эндпоинт не документирован: если он изменится, провайдер просто не определится. Страна запасным путём — из `cloudflare.com/cdn-cgi/trace`. Отключить поиск — `--no-lookup`. Тип сети определяется по интерфейсу маршрута по умолчанию (Wi-Fi, кабель, модем); в контейнере Docker виден только виртуальный `eth0`, поэтому там `net` не будет — различайте условия метками (`--tag mobile-mts`) или переменной `ZOO_PROBE_NET=cellular`.

Как читается рейтинг — `zoo probe --rank` (README, раздел «История проб и рейтинг»).
