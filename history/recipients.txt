# Формат — по строке: ssh-ed25519 …, ssh-rsa … или age1… ; строки с # и пустые игнорируются.
# Добавить свой ключ (на своей машине):  cat ~/.ssh/id_ed25519.pub >> history/recipients.txt
# Расшифровать:  scripts/history.sh decrypt history/raw/<id>.json.age   (history/README.md)
#
# Пока здесь нет ни одного ключа, `scripts/history.sh pull` и пробник с --history-dir
# сохраняют только анонимный jsonl, без сырых отчётов.
