# 🦓 vpn-zoo-installer

![Ubuntu](https://img.shields.io/badge/Ubuntu-22.04%20%7C%2024.04-E95420?logo=ubuntu&logoColor=white)
![Лицензия](https://img.shields.io/badge/лицензия-MIT-blue)

VPN для команды в России на одном сервере: несколько протоколов сразу и админка, через которую сисадмин подключает сотрудников и разбирается, если у кого-то не работает. Через VPN идут только выбранные приложения; банки, Госуслуги и MAX работают напрямую и адреса сервера не видят.

## Установить

На чистой Ubuntu 22.04/24.04 под root:

```bash
apt-get update && apt-get install -y git && git clone https://github.com/Art-Frich/vpn-zoo-installer.git /opt/vpn-zoo-src && bash /opt/vpn-zoo-src/scripts/install.sh
```

В конце установка проверит протоколы и напечатает команду входа в админку. Подробно — [установка и что вы получите](docs/REFERENCE.md#установка).

## Открыть админку

```bash
ssh -t -L 7070:127.0.0.1:7070 root@IP zoo web --link
```

Пароль сервера → ссылка → браузер. Админка работает, пока открыто окно.
