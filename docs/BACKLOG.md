# Бэклог админки и зоопарка

Рабочий план правок (технические детали — [PLAN-admin.md](PLAN-admin.md)). Берём по одному пункту сверху, каждый проходит цикл ниже.
Пункты из ревью-роя (research/2026-10-06/admin-review_06-10-26.md) вливаются сюда после его завершения.

## Цикл на каждый пункт

1. **Сделать** — минимальная правка, без попутных «улучшений».
2. **Саморевью диффа** (`git diff`) по чек-листу:
   - нет приватных данных (IP, токены, ключи, пароли) в коде, тестах, коммите;
   - нагрузка на сервер: нет тяжёлых вызовов на рендере страницы, всё дорогое — по таймеру или кэшу;
   - безопасность: POST + CSRF, никаких данных пользователя в argv/shell, права root только где нужно;
   - текст: можно ли убрать половину слов; терминология единая (AmneziaWG 3.1 и т.п.);
   - работает без JS (базово) и на ширине телефона.
3. **Тесты** — `python -m unittest` в zoo/ + нужный набор `docker/test.sh --tests …`.
4. **Деплой на тестовый VPS** одним SSH-подключением, **замер** (время страниц, CPU/трафик таймера) — цифры только измеренные.
5. **Глазами** — открыть страницу, проверить то, что просил пользователь.
6. Коммит + push в main, отметка здесь.

## Отложено пользователем

- Приёмочный прогон строго по README на чистом сервере (можно эмулировать в Docker).
- Находка 7 (обрывы VLESS+Vision/SS) — проверить у другого хостера.
- Тесты с мобильной сети/телефона.

## Ждёт решения пользователя

- Перезагрузка тестового сервера (ядро 6.8.0-142).
- Переписать историю git, чтобы убрать IP из 3b04857 (force-push).
- Смена токена админки после тестов; уборка в конце (маршрут /32, probe/probe-export.json).
