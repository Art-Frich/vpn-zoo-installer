# Решения (принятые без владельца, 2026-10-04)

Владелец делегировал работу на ночь. Здесь перечислены решения, которые обычно оставались бы за ним, с обоснованием. Любое можно пересмотреть.

| # | Решение | Почему | Как поменять |
|---|---|---|---|
| D1 | Все внешние компоненты закреплены в `scripts/versions.env` и проверяются по sha256. `latest` больше не используется | `latest` принёс pre-release Xray, который отрезал sing-box-клиентов. Закрепление снимает весь класс проблем [версия] | правка `versions.env` + `zoo upgrade` |
| D2 | Hysteria2 остаётся standalone (apernet), а не внутри 3x-ui | Работает у владельца в поле. В apernet есть Salamander/Gecko, port hopping и trafficStats API. Вариант через Xray не проверен по скорости | `HY2_ENGINE` (резерв на будущее) |
| D3 | AmneziaWG: `AWG_ENGINE=auto` — ядро, если DKMS собирается, иначе userspace amneziawg-go | Ядро быстрее. Userspace работает везде, в том числе в Docker и на ядрах, где DKMS ломается | `AWG_ENGINE=kernel\|userspace` |
| D4 | Параметры AWG генерируются уникально на каждую установку, совместимы с клиентами AWG 2.0. Расширения 3.x (HPK, RandomTrailers) — по флагу | Статичные параметры одинаковы у всех установок и служат сигнатурой. В клиентах 2.0 3.x-расширения ломаются | `AWG_PROFILE=v2\|v3` |
| D5 | Новые протоколы: XHTTP+REALITY (вкл.), Shadowsocks-2022 (вкл.), TUIC v5 (выкл.), Hy2-Salamander (выкл.), WARP (выкл.) | XHTTP — второй TCP у рабочих сервисов. SS-2022 — не-TLS запасной. Остальное за флагами, чтобы не раздувать поверхность | флаги `ENABLE_*` |
| D6 | Панель 3x-ui слушает только `127.0.0.1`, доступ через `ssh -L` | Открытая HTTP-панель — фактор бана и утечки ключей | — |
| D7 | Админка — инструмент `zoo` (Python 3 stdlib: CLI + веб на 127.0.0.1) поверх 3x-ui | 3x-ui не видит standalone Hy2 и ядерный AWG. Нужен единый вид: все протоколы, пользователи, трафик, метрики. stdlib — ноль зависимостей | — |
| D8 | Публичная подписка 3x-ui по умолчанию выключена. Ссылки и QR выдаёт `zoo` | Подписка без домена и TLS отдаёт ключи открытым текстом и открывает порт под сканер. С доменом включается флагом | `SUB_PUBLIC=1 DOMAIN=...` |
| D9 | Анти-утечки по умолчанию: echo-сервисы → WARP (если включён) или блок; RU-egress = `direct` | Блок RU на сервере ломает банки у клиентов без сплита. Echo-правило безопасно и закрывает канал утечки IP | `RU_EGRESS=block\|warp` |
| D10 | REALITY target выбирается валидатором из списка кандидатов, а не `www.cbr.ru` | cbr.ru: несоответствие SNI и ASN, предупреждение ядра, нет ML-KEM | `VLESS_SNI=...` |
| D11 | Второй сервер не обязателен. «Работает в принципе» проверяется с самого сервера, «блокируется ли» — пробником с машины пользователя | Самопроверка сервера плюс клиентский прогон дают оба ответа | — |
| D12 | unattended-upgrades с автоперезагрузкой в 04:00 по умолчанию | Новые ядра и libc без перезагрузки не применяются; у одиночного VPN-сервера нет пользователей, которых reboot прервёт | `AUTO_REBOOT=0`, `AUTO_REBOOT_TIME=ЧЧ:ММ` |
| D13 | Пароль панели задаётся через API (`setting/updateUser`, тело запроса), а не `x-ui setting -password` | argv виден всем процессам. На свежей БД панель стартует с admin/admin только на 127.0.0.1 и за UFW, смена занимает секунды. При отказе API — фолбэк на argv с предупреждением | — |
| D14 | State первой версии инсталлера (без `__schema`) сбрасывается: все фазы проходят заново, компоненты v1 помечаются «нашими» | Фазы v1 устарели (3x-ui latest, панель наружу, 8443); новые фазы идемпотентны и сами мигрируют | `install.sh --phase X` |
| D15 | 2FA панели выключена по умолчанию | Панель доступна только через SSH-туннель; потерянный TOTP-секрет — лишний риск блокировки | `PANEL_2FA=1` (секрет в config.env) |
